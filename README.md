# 📋 DataPribadi App - Full-Stack CRUD Application

Aplikasi pengelolaan data pribadi berbasis web yang dibangun dengan arsitektur terpisah antara Back-End (RESTful API) dan Front-End interaktif. Aplikasi ini dilengkapi dengan pencarian dinamis, validasi data, dan kalkulasi umur otomatis secara real-time.

---

## 🛠️ Tech Stack

**Back-End:**
* **Java 17**
* **Spring Boot 3.2.5** (Spring Data JPA, Web)
* **H2 Database** (In-Memory Database)
* **Maven**

**Front-End:**
* **HTML5 & CSS3**
* **Bootstrap 5** (UI Framework & Icons)
* **JQuery & AJAX** (Asynchronous API Requests)

---

## ✨ Fitur Utama

* **CRUD Operations:** Tambah, lihat detail, perbarui, dan hapus data pribadi.
* **Real-time Age Calculation:** Kalkulasi umur dinamis berbasis `java.time.Period` di Back-End.
* **Flexible Search:** Fitur pencarian data berdasarkan NIK maupun Nama.
* **Data Validation & Protection:** Proteksi duplikasi NIK pada tingkat controller & database.
* **Responsive UI:** Tampilan modern, bersih, dan responsif menggunakan Bootstrap 5 & Inter Font.
